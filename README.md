# Vision Forge — Portfolio Website

React + Vite + Tailwind + GSAP marketing site for Vision Forge (Belize).

**Live:** https://nonchxlantdev.github.io/visionforge-portfoliowebsite/

## Local development

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Stack

- React 19 + Vite 8
- Tailwind CSS 4
- GSAP (ScrollTrigger) for scroll reveals / nav
- Motion for service card tilt
- OGL WebGL ferrofluid hero background

## Security & performance notes

- External links use `rel="noopener noreferrer"`
- WebGL pauses when off-screen or when the tab is hidden
- Interactions respect `prefers-reduced-motion`
- Production builds ship to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)
